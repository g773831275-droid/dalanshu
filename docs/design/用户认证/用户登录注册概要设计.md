# 用户登录注册概要设计

> 文档类型：概要设计  
> 建设阶段：第一阶段  
> 接口清单：[大蓝树前后端接口汇总](../../api/大蓝树前后端接口汇总.md)

## 1. 建设目标

第一阶段建立统一的平台账号体系，为大蓝树用户端和管理端提供注册、登录、令牌刷新、退出、密码恢复和个人资料能力。

## 2. 第一阶段范围

- 用户使用手机号短信验证码注册，注册时必须设置密码。
- 注册成功后自动登录并返回访问令牌和刷新令牌。
- 登录支持“手机号 + 密码”。
- 已绑定邮箱的兼容账户仍可通过邮箱重置密码；用户端暂不提供密码恢复页面。
- 注册短信只用于手机号注册验证码；账号恢复仍通过已验证邮箱完成。
- 使用后端默认租户，用户端不展示、不传递租户标识。
- 支持获取和修改大蓝树产品资料，并记录用户最近使用的 Web 设备。
- 微信扫码登录单独设计，不纳入本功能的第一阶段交付范围。

## 3. 账号与资料模型

### 3.1 平台账号

- `sys_user` 保存平台账号、密码、手机号、兼容的邮箱字段和基础资料。
- 手机号是注册和登录身份凭证，在默认租户内唯一，并在注册时通过短信验证码验证。
- 邮箱保留给后台兼容能力和密码恢复，在默认租户内唯一。
- `user_name` 是系统内部唯一用户名，由后端生成，不允许用户填写，也不直接使用手机号。
- `sys_social` 保存微信等第三方身份，不把第三方 OpenID 作为平台主键。

### 3.2 大蓝树产品资料

大蓝树昵称、简介、性别、年龄段、地域和统计字段属于产品资料，通过 `/api/v1/me/profile` 读写。后台 RuoYi 个人资料接口 `/system/user/profile` 继续服务管理端，两者不得混为同一套前端接口。

### 3.3 设备信息

登录或注册成功后，用户端通过 `/api/v1/me/device` 上报设备类型、品牌、型号、操作系统、浏览器、屏幕、语言和时区，用于运营画像。设备 ID 仅用于同一浏览器内识别，不作为认证凭据。

## 4. 数据规则

| 字段或数据 | 规则 |
|---|---|
| `email` | 后台兼容与密码恢复使用，去除首尾空格并按小写比较；默认租户内唯一 |
| `phonenumber` | 中国大陆 11 位手机号，满足 `^1[3-9]\d{9}$`，默认租户内唯一 |
| `user_name` | 使用 `u_ + 唯一编码`，不得拼接手机号 |
| `password` | 使用 BCrypt 保存，不得记录、返回或打印明文 |
| `register_source` | 建议记录注册来源，手机号注册为 `sms` |
| 短信验证码 | 仅用于注册，单次使用且具有有效期 |
| refresh token | 成功刷新后轮换，旧 refresh token 失效 |

## 5. 核心流程

### 5.1 手机号注册

输入手机号 → 发送短信验证码 → 提交手机号、验证码和密码 → 注入默认租户 → 校验手机号唯一性 → 生成内部用户名 → 创建用户并分配普通用户角色 → 自动登录 → 返回令牌 → 上报设备信息。

### 5.2 密码登录

获取图形验证码 → 提交手机号及密码 → 注入默认租户 → 查找并校验用户状态与密码 → 返回访问令牌和刷新令牌 → 上报设备信息。

### 5.3 刷新令牌

访问令牌失效 → 前端提交 refresh token → 后端校验签名、有效期和会话 → 轮换访问令牌与 refresh token → 前端保存新令牌 → 重试原请求。刷新失败时清除本地令牌并要求重新登录。

### 5.4 保留的邮箱恢复密码

获取图形验证码 → 发送 `recover` 用途邮箱验证码 → 提交邮箱、验证码和新密码 → 更新密码 → 注销该用户旧会话 → 用户重新登录。

发送恢复验证码时，无论邮箱是否存在都应返回相同提示，避免泄露平台注册情况。

### 5.5 个人资料

用户可修改昵称、简介、性别、年龄段和地域。手机号、邮箱、头像等账号级资料若继续使用 RuoYi 接口维护，必须明确消费端和权限；后续可统一迁入大蓝树 `/api/v1/me/*` 接口。

## 6. 安全与限流

1. 注册、登录和密码恢复均校验用户、租户与客户端状态。
2. 短信验证码设置有效期、发送间隔、每日上限和单次消费。
3. 短信发送按手机号限流。
4. 停用、逻辑删除或所属租户停用的用户禁止登录。
5. 密码重置后注销旧会话；日志不得包含密码、验证码、访问令牌和 refresh token。
6. 生产环境的 JWT 密钥、SMTP 授权码等只通过环境变量注入。

## 7. 当前实现边界

- React 用户端已接入注册、登录、刷新、退出、当前用户、产品资料和设备上报。
- React 用户端尚未接入密码恢复页面。
- 后端保留邮箱可用性检查与邮箱找回兼容接口；Vue 管理端旧注册页不纳入本次 React 用户端改造。
- 手机号注册用户默认分配“普通用户”角色，角色编码为 `normal_user`，数据范围为“仅本人”，不授予管理端菜单权限。
- 手机号找回密码、邮箱换绑和用户主动注销尚未纳入当前实现。
- 代码中真实存在的接口与联调状态只维护在[大蓝树前后端接口汇总](../../api/大蓝树前后端接口汇总.md)，本设计不重复维护接口表。

## 8. 验证码服务

- 注册验证码通过火山引擎短信服务发送。
- 短信服务凭据仅通过环境变量或密钥管理服务注入，禁止提交到 Git。
- 注册验证码真实发送，任何环境都不向前端回传验证码。
- 已绑定邮箱的兼容账户重置密码时仍使用 SMTP 邮件验证码。

## 9. 待确认

2. 短信验证码有效期、发送间隔和每日上限。
3. 手机号与邮箱换绑是否在第二阶段建设。
4. 用户主动注销及数据保留规则。
