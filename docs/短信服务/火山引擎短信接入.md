# 火山引擎短信接入

## 已接入的接口

`GET /api/v1/auth/sms/code?phonenumber=13800138000` 使用火山引擎 `SendSms` 发送 6 位注册验证码。验证码由本地生成并缓存到 Redis，校验时从 Redis 取出比对，校验成功后立即删除。接口对每个手机号限制为每分钟一次。

大蓝书前台注册使用手机号和短信验证码；注册成功后通过设置的密码完成自动登录。手机号在当前租户下唯一。

## 厂商切换

本通道为备选实现。如需切换到阿里云号码认证服务，将环境变量 `DALANSHU_SMS_PROVIDER` 改为 `aliyun` 并重启服务即可，详见 [短信服务总览](./README.md)。

## 环境变量

```bash
DALANSHU_SMS_PROVIDER=volc

DALANSHU_VOLC_SMS_ENABLED=true
DALANSHU_VOLC_SMS_ACCESS_KEY=AK...
DALANSHU_VOLC_SMS_SECRET_KEY=...
DALANSHU_VOLC_SMS_ACCOUNT=短信子账户的subAccountId
DALANSHU_VOLC_SMS_SIGN=大蓝书
DALANSHU_VOLC_SMS_REGISTER_TEMPLATE_ID=SPT_...
DALANSHU_VOLC_SMS_CODE_EXPIRE_MINUTES=5
DALANSHU_VOLC_SMS_DAILY_MAX=30
DALANSHU_VOLC_SMS_REGION=cn-north-1
```

## 参数说明

- `DALANSHU_VOLC_SMS_SIGN` 对应 `SendSms` 请求中的 `Sign`，填写审核通过的签名文字。控制台显示的 `S1T_...` 签名资源 ID 不应直接填入该变量；请以火山引擎控制台模板详情和 `SendSms` 文档的字段为准。
- `DALANSHU_VOLC_SMS_ACCOUNT` 对应 `SendSms` 请求中的 `SmsAccount`。在短信服务的"子账户管理"中复制 `subAccountId`，不要使用签名 ID 或模板 ID。
- `DALANSHU_VOLC_SMS_REGISTER_TEMPLATE_ID` 对应 `SendSms` 请求中的 `TemplateId`，在火山引擎短信控制台"模板管理"中复制模板 ID（`SPT_` 开头）。
- `DALANSHU_VOLC_SMS_CODE_EXPIRE_MINUTES` 验证码有效期（分钟），必须与短信模板文案中的有效期一致，默认 5。
- `DALANSHU_VOLC_SMS_DAILY_MAX` 单个手机号 24 小时内最大发送量，默认 30。
- `DALANSHU_VOLC_SMS_REGION` 火山引擎短信服务区域，默认 `cn-north-1`。

## 模板示例

注册模板使用变量 `code`：

```text
【大蓝书】您正在注册账号，验证码为：${code}。验证码5分钟内有效，请勿泄露给他人。
```

模板文案中的有效期应与 `DALANSHU_VOLC_SMS_CODE_EXPIRE_MINUTES` 保持一致，默认均为 5 分钟。

## 频控

接口按手机号限制为每分钟一次（由 `@RateLimiter` 注解强制），并且默认每 24 小时最多发送 `DALANSHU_VOLC_SMS_DAILY_MAX` 条（通过 Redis 限流器计数）。可通过该变量调整每日上限。

## 安全

`DALANSHU_VOLC_SMS_SECRET_KEY` 仅在部署环境中设置，禁止提交到仓库或写入 YAML。
