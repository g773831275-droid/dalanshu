# 火山引擎短信直连调试

脚本 [volc_sms_demo.py](../../script/volc_sms_demo.py) 可调用项目 Java 短信接口，或使用标准库直接调用火山引擎 `SendSms`。Java 接口模式不需要在 Python 进程中配置 AK/SK。

## 推荐：调用 Java 服务

先启动已配置短信环境变量的 Java 服务，再执行：

```bash
python3 script/volc_sms_demo.py --java-url http://127.0.0.1:8080 --phone <手机号>
```

该方式调用 `GET /api/v1/auth/sms/code`。验证码由 Java 服务生成并发送；Python 不参与火山引擎签名。

## 直连火山引擎：配置环境变量

```bash
export DALANSHU_VOLC_SMS_ACCESS_KEY='AK...'
export DALANSHU_VOLC_SMS_SECRET_KEY='...'
export DALANSHU_VOLC_SMS_ACCOUNT='短信子账户的 subAccountId'
export DALANSHU_VOLC_SMS_SIGN='杭州红热科技有限公司'
export DALANSHU_VOLC_SMS_REGISTER_TEMPLATE_ID='SPT_...'
```

`SmsAccount` 必须是短信服务子账户的 `subAccountId`。签名 ID（`S1T_...`）和模板 ID（`SPT_...`）不能代替它。

## 直连火山引擎：发送测试

```bash
python3 script/volc_sms_demo.py --phone <手机号> --code 123456
```

`--phone` 为必填参数，仅接受中国大陆 11 位手机号码，例如：

```bash
python3 script/volc_sms_demo.py --phone 15970865755 --code 123456
```

脚本默认传递 `{"code":"123456"}`。若控制台模板变量名是 `content`，改用：

```bash
python3 script/volc_sms_demo.py --phone 15970865755 --code 123456 --param-name content
```

请求体字段与火山引擎 `SendSms` 示例一致：`SmsAccount`、`Sign`、`TemplateID`、`TemplateParam`、`PhoneNumbers` 和 `Tag`。
