# 阿里云短信接入

## 已接入的接口

`GET /api/v1/auth/sms/code?phonenumber=13800138000` 使用阿里云号码认证服务 `SendSmsVerifyCode` 发送 6 位注册验证码。验证码由阿里云侧生成并缓存，调用 `CheckSmsVerifyCode` 由阿里云侧校验。接口对每个手机号限制为每分钟一次。

大蓝书前台注册使用手机号和短信验证码；注册成功后通过设置的密码完成自动登录。手机号在当前租户下唯一，短信验证码校验成功后由阿里云侧标记失效。

## 厂商切换

本通道为默认实现。如需切换到火山引擎，将环境变量 `DALANSHU_SMS_PROVIDER` 改为 `volc` 并重启服务即可，详见 [短信服务总览](./README.md)。

## 环境变量

```bash
DALANSHU_SMS_PROVIDER=aliyun

DALANSHU_ALIYUN_SMS_ENABLED=true
DALANSHU_ALIYUN_SMS_ACCESS_KEY_ID=LTAI...
DALANSHU_ALIYUN_SMS_ACCESS_KEY_SECRET=...
DALANSHU_ALIYUN_SMS_SIGN=恒创联众
DALANSHU_ALIYUN_SMS_REGISTER_TEMPLATE_CODE=100001
DALANSHU_ALIYUN_SMS_TEMPLATE_PARAM={"code":"##code##","min":"5"}
DALANSHU_ALIYUN_SMS_CODE_TYPE=1
DALANSHU_ALIYUN_SMS_CODE_LENGTH=6
DALANSHU_ALIYUN_SMS_VALID_TIME=300
DALANSHU_ALIYUN_SMS_INTERVAL=60
DALANSHU_ALIYUN_SMS_DAILY_MAX=30
DALANSHU_ALIYUN_SMS_RETURN_VERIFY_CODE=false
DALANSHU_ALIYUN_SMS_REGION=cn-hangzhou
```

## 参数说明

- `DALANSHU_ALIYUN_SMS_SIGN` 对应 `SendSmsVerifyCode` 的 `SignName`，填写审核通过的签名文字，例如"恒创联众"。
- `DALANSHU_ALIYUN_SMS_REGISTER_TEMPLATE_CODE` 对应 `TemplateCode`。号码认证服务赠送模板可直接填 `100001`；自定义模板填控制台显示的模板 CODE。
- `DALANSHU_ALIYUN_SMS_TEMPLATE_PARAM` 对应 `TemplateParam`，需与模板变量一致。赠送模板使用 `{"code":"##code##","min":"5"}`（实际发送时 `##code##` 由阿里云替换为验证码）；如使用自定义模板，按模板变量调整。
- `DALANSHU_ALIYUN_SMS_CODE_TYPE` 验证码类型，`1` 表示数字（默认）。
- `DALANSHU_ALIYUN_SMS_CODE_LENGTH` 验证码长度，4–8 位，默认 6。
- `DALANSHU_ALIYUN_SMS_VALID_TIME` 验证码有效期（秒），默认 300。
- `DALANSHU_ALIYUN_SMS_INTERVAL` 同一手机号最短发送间隔（秒），默认 60。
- `DALANSHU_ALIYUN_SMS_RETURN_VERIFY_CODE` 是否在响应中返回明文验证码，默认 `false`。仅在测试环境调试时设为 `true`。
- `DALANSHU_ALIYUN_SMS_REGION` 接入点区域，默认 `cn-hangzhou`。

## 频控

接口按手机号限制为每分钟一次（由 `@RateLimiter` 注解强制），并且默认每 24 小时最多发送 `DALANSHU_ALIYUN_SMS_DAILY_MAX` 条（通过 Redis 限流器计数）。可通过该变量调整每日上限。

## 安全

`DALANSHU_ALIYUN_SMS_ACCESS_KEY_SECRET` 仅在部署环境中设置，禁止提交到仓库或写入 YAML。

## 自定义模板示例

如不使用赠送模板，需在阿里云号码认证服务控制台申请模板，模板内容示例：

```text
【恒创联众】您正在注册账号，验证码为：${code}。验证码5分钟内有效，请勿泄露给他人。
```

模板文案中的有效期应与 `DALANSHU_ALIYUN_SMS_VALID_TIME` 换算后保持一致（默认 300 秒 = 5 分钟）。

## 测试注意事项

`13800138000` 是常见的虚假测试手机号，阿里云号码认证服务对其返回 `UNKNOWN UNKNOWN`。本地联调时请使用真实手机号，否则会误判为接口异常。
