# 阿里云内容安全接入

大蓝书的用户生成内容使用阿里云 Content Moderation 2022-03-02 API 进行同步审核：

- 文本：帖子标题、正文、话题、评论、圈子名称和简介、昵称及个人简介。
- 图片：`POST /api/v1/uploads` 上传的 JPEG、PNG、WebP、GIF；只有审核通过后才返回 OSS 地址。

审核已启用时，文本命中风险标签或图片 `RiskLevel` 不为 `none` 会返回 `422 CONTENT_MODERATION_REJECTED`。阿里云接口异常、超时或配置不完整会返回 `503`，不会绕过审核。图片审核失败时已上传的 OSS 对象和记录会立即删除。

## 部署配置

先在阿里云开通内容安全，并为 RAM 用户授予 `AliyunYundunGreenWebFullAccess`。生产环境通过环境变量或密钥管理服务设置：

```bash
DALANSHU_CONTENT_MODERATION_ENABLED=true
DALANSHU_CONTENT_MODERATION_ACCESS_KEY_ID=AK...
DALANSHU_CONTENT_MODERATION_ACCESS_KEY_SECRET=...
DALANSHU_CONTENT_MODERATION_REGION=cn-shanghai
DALANSHU_CONTENT_MODERATION_ENDPOINT=green-cip.cn-shanghai.aliyuncs.com
```

可选服务参数保持默认即可：`DALANSHU_CONTENT_MODERATION_TEXT_SERVICE=comment_detection`、`DALANSHU_CONTENT_MODERATION_IMAGE_SERVICE=postImageCheck`。更换地域时必须同时使用该地域的内容安全接入地址与已开通的服务。

开发环境默认关闭。需要本地联调时，在仓库外的 `~/.config/dalanshu/content-moderation.properties` 设置同名环境属性；不要把 AK/SK 写入 YAML 或提交到仓库。
