# 首页运营配置说明

## 功能入口

执行 `script/sql/update/dalanbook_home_placement.sql` 后，管理端“大蓝书运营”目录下新增“首页运营”。页面按“广告弹窗”和“置顶公告”两个标签管理内容，现有 `content_operator` 角色会自动获得列表、新增、编辑和删除权限。

迁移脚本可重复执行。它创建 `dalan_home_placement` 表、查询索引、菜单和以下权限：

```text
dalanbook:home-placement:list
dalanbook:home-placement:add
dalanbook:home-placement:edit
dalanbook:home-placement:remove
```

## 配置规则

广告弹窗必须填写标题并上传一张 JPEG、PNG 或 WebP 图片，图片不能超过 5 MB。保存时后端会再次检查 OSS 对象、文件格式和已记录的文件大小。编辑广告会递增展示版本，因此已经看过旧版本的浏览器可以看到更新后的版本。

置顶公告必须填写标题和纯文本正文，摘要用于首页紧凑横幅。公告详情直接在页面内弹窗展示，不解析富文本。

两种类型均支持优先级、开始时间、结束时间和发布状态。按钮文案和目标链接必须同时填写或同时留空；链接只接受以单个 `/` 开头的站内路径或绝对 HTTPS 地址。

## 生效与排序

记录同时满足以下条件时生效：

- 状态为 `published`。
- 开始时间为空，或不晚于当前时间。
- 结束时间为空，或晚于当前时间。

同类型有多条生效内容时，优先级数值最高的记录胜出；优先级相同则取最近发布的一条。隐藏后重新发布会刷新发布时间。删除操作把状态更新为 `deleted`，数据不会物理删除。

## 管理 API

管理接口统一位于 `/dalanbook/admin/home-placements`：

```text
GET    /dalanbook/admin/home-placements
GET    /dalanbook/admin/home-placements/{id}
POST   /dalanbook/admin/home-placements
PUT    /dalanbook/admin/home-placements/{id}
DELETE /dalanbook/admin/home-placements/{id}
```

分页查询支持 `placementType`、`status`、`keyword`、`pageNum` 和 `pageSize`。运营位类型创建后不可修改。

## 发布与回滚

发布前先以 `hidden` 状态保存并核对图片、摘要、正文、按钮和投放时间，再切换为 `published`。紧急撤回只需改为 `hidden`，Web 最多约 60 秒停止展示。

如需回滚整个功能，先下线应用代码，再删除菜单与角色关联，最后删除数据表：

```sql
DELETE FROM sys_role_menu WHERE menu_id IN (19004, 19016, 19017, 19018);
DELETE FROM sys_menu WHERE menu_id IN (19016, 19017, 19018, 19004);
DROP TABLE IF EXISTS dalan_home_placement;
```

回滚会永久删除运营数据，应在执行前备份 `dalan_home_placement`。
