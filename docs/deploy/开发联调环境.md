| 用途 | 公网地址 | 本机服务 | 本机端口 |
| --- | --- | --- | ---: |
| 管理后台 | `https://dev-admin.scarletmoon.tech` | `plus-ui` | 5173 |

三个域名的 A 记录均指向 `82.156.43.138`。

## 转发拓扑

```text
HTTPS 域名
  -> Ubuntu Caddy :443
  -> Ubuntu FRPS HTTP vhost :8080
  -> FRP 控制连接 :7000
  -> 本机 FRPC
  -> 127.0.0.1:5173 / 5174 / 8080
```

Ubuntu 上 Caddy、FRPS 为常驻服务；本机 FRPC 由 LaunchAgent `com.scarletmoon.frpc` 管理。

实际配置：`~/.config/frp/frpc.toml`

项目内无密钥参考模板：`script/frp/frpc-dalanshu.example.toml`

## 本机 Server 连接云端开发库

云 MySQL 不开放公网地址。各研发人员通过自己的 ECS SSH 账号建立本地端口转发，本机 `ruoyi-admin` 统一连接 `127.0.0.1:13306` 上的 `dalanshu_dev` 数据库。

### 1. 准备 SSH 账号

每位研发人员必须使用独立的 ECS 账号和 SSH 密钥，禁止共享 `root` 密码。本机尚无 SSH 密钥时执行：

```bash
ssh-keygen -t ed25519 -a 64 -C "<ssh-user>@dalanshu"
cat ~/.ssh/id_ed25519.pub
```

只将 `.pub` 公钥提交给管理员绑定；私钥不得上传、共享或提交到 Git。

### 2. 启动 SSH 隧道（每次开机后执行）

将 `<ssh-user>` 替换为管理员分配的 ECS 账号，例如 `dev-zhang`：

```bash
ssh -fN -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:13306:172.31.10.95:3306 <ssh-user>@118.196.139.226
```

`-fN` 会让 SSH 隧道在后台运行，关闭当前终端不会中断隧道。命令没有报错且返回命令行后，执行：

```bash
lsof -nP -iTCP:13306 -sTCP:LISTEN
```

应看到 `ssh` 进程监听 `127.0.0.1:13306`。如果提示 `Address already in use`，通常表示隧道已经启动，不要重复执行。

如需关闭隧道，先从上述 `lsof` 结果找到 PID，再执行：

```bash
kill <PID>
```

### 3. 配置本机私密配置

SSH 用户名由启动脚本从 `dev.env` 读取：

```bash
mkdir -p ~/.config/dalanshu
cp script/env/dev.env.example ~/.config/dalanshu/dev.env
chmod 600 ~/.config/dalanshu/dev.env
```

编辑 `~/.config/dalanshu/dev.env`，填写管理员分配的 ECS 账号。

Spring Boot 的 `dev` Profile 会直接加载以下位于 Git 仓库外的私密配置文件：

| 文件 | 必需配置 |
| --- | --- |
| `~/.config/dalanshu/database.properties` | `DALANSHU_DB_PASSWORD` |
| `~/.config/dalanshu/redis.properties` | `DALANSHU_REDIS_PASSWORD` |
| `~/.config/dalanshu/mail.properties` | `DALANSHU_MAIL_PASSWORD` |
| `~/.config/dalanshu/tos.properties` | TOS AK、SK、Bucket、Region 等对象存储配置 |

创建邮件配置：

```bash
cp script/env/mail.properties.example ~/.config/dalanshu/mail.properties
chmod 600 ~/.config/dalanshu/mail.properties
```

编辑 `mail.properties`，填写阿里云 DirectMail 发信地址对应的 SMTP 密码。真实密码不得写入项目文件、开发手册或提交到 Git。

### 4. 启动本机后端

推荐使用统一启动脚本。它会加载 SSH 用户配置、检查外部私密配置、自动启动 SSH 隧道，然后使用 `dev` Profile 启动 `ruoyi-admin`：

```bash
./script/bin/run-dev-cloud.sh
```

开发环境默认数据库连接为 `127.0.0.1:13306/dalanshu_dev`，用户为 `dalanshu_dev_app`。邮箱注册和找回密码验证码使用阿里云 DirectMail，发件地址为 `cilantro@mail.idalanshu.com`。

如果使用 IntelliJ IDEA 直接启动，无需在 Run Configuration 中重复填写数据库、Redis、TOS 或 SMTP 密码；Spring Boot 会读取上述 `.properties` 文件。启动前仍需手工建立 SSH 隧道，并确认激活 `dev` Profile。修改外部配置后必须完整重启 Java 进程。

### 5. 账号和权限约定

- `dalanshu_dev_app`：开发环境应用账号，可由所有研发人员的本机 Server 共用，仅拥有 `dalanshu_dev` 的业务数据读写权限。
- `dev_<name>`：研发人员人工登录账号，一人一号，用于 DataGrip 查询、调试和必要的开发库 DDL。
- `dalanshu_prod_app`：生产应用账号，仅保存在生产 ECS，不向研发人员分发。
- 开发时仅连接 `dalanshu_dev`，不得将本机 Server 指向 `dalanshu_prod`。

### 6. 常见问题

- `Connection refused 127.0.0.1:13306`：SSH 隧道未启动或已断开。
- `Address already in use`：本机 `13306` 已有隧道或其他进程监听。
- `Access denied for user`：应用账号密码错误，或账号尚未获授 `dalanshu_dev` 权限。
- SSH 可登录但 MySQL 超时：联系管理员检查 RDS 白名单、VPC 和 ECS 到 `172.31.10.95:3306` 的私网连通性。
- `邮件服务未配置`：缺少 `~/.config/dalanshu/mail.properties`，或其中的 `DALANSHU_MAIL_PASSWORD` 为空。
- SMTP `535 Authentication failure`：`mail.properties` 中的值不是当前发信地址对应的 SMTP 密码；修正后完整重启 Java 进程。
- `邮箱验证码发送失败`：检查 DirectMail 发信地址状态、SMTP 密码和到 `smtpdm.aliyun.com:465` 的网络连通性。

## FRPC 配置

```toml
serverAddr = "82.156.43.138"
serverPort = 7000
user = "macbook"

transport.protocol = "tcp"
transport.tls.enable = true
transport.tls.serverName = "82.156.43.138"
transport.tls.trustedCaFile = "/Users/dante/.config/frp/ca.crt"
transport.wireProtocol = "v2"

auth.method = "token"
auth.tokenSource.type = "file"
auth.tokenSource.file.path = "/Users/dante/.config/frp/token"

[[proxies]]
name = "plus-ui"
type = "http"
localIP = "127.0.0.1"
localPort = 5173
subdomain = "dev-admin"

[[proxies]]
name = "dalanbook-frontend"
type = "http"
localIP = "127.0.0.1"
localPort = 5174
subdomain = "dev-web"

[[proxies]]
name = "java-api"
type = "http"
localIP = "127.0.0.1"
localPort = 8080
subdomain = "dev-api"
```

## 前端 API 约定

- 外部开发者直接访问 `https://dev-api.scarletmoon.tech`。
- `plus-ui` 本地开发继续使用 `/dev-api`，由 Vite 转发到本机 `http://localhost:8080`。
- `dalanbook-frontend` 接入真实接口后，开发环境 API 地址使用 `https://dev-api.scarletmoon.tech`。
- 两个 Vite 服务使用固定端口并启用 `strictPort`，禁止端口占用时自动漂移。

## 暴露范围

- 仅暴露 5173、5174、8080 三个 HTTP 服务。
- MySQL、Redis、MinIO、Spring Boot Admin、SnailJob 等端口不得通过 FRP 暴露。
- 当前后端允许跨域访问；正式部署前必须收紧为可信域名。
- FRP 令牌仅保存在 `~/.config/frp/token`，不得写入项目或提交到 Git。
- `~/frpc.toml` 是废弃的旧开发配置，不作为当前运行配置。
