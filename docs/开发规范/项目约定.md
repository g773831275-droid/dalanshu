# 项目开发约定

## 基本原则

- 优先沿用 RuoYi-Vue-Plus 现有模块划分、命名、异常处理和响应结构，不重复制定通用规范。
- 新业务按模块归档文档：`docs/模块名/`。
- 数据库变更必须提供增量 SQL，放入 `script/sql/update/`，禁止只改本机数据库。
- 密码、授权码、密钥等敏感信息只能通过环境变量提供，禁止提交到 Git。

## 当前项目决策

- 默认租户由后端注入，客户端不选择、不传租户。
- 用户永久唯一标识为 `user_id`；邮箱和手机号只是登录凭证。
- 内部用户名由后端生成，格式为 `u_ + 唯一编码`。
- 邮箱在同一租户内唯一；有效用户手机号在同一租户内唯一。
- 国际手机号统一使用 E.164 格式。
- 认证接口沿用项目现有 API 加密机制。
- 首期邮件使用 QQ SMTP；全局搜索 `TODO DALANSHU_MAIL_PROVIDER` 可定位未来切换火山引擎邮件推送的位置。

## Git

- `main`：稳定分支。
- `develop`：日常集成分支。
- 功能开发从 `develop` 创建短期分支，合并后删除。
