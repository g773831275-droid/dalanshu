# 发布帖子页 API 契约

## 1. 文档信息

- 页面：普通用户端发布页 `/publish`
- API 版本：v1
- Base URL：`/api/v1`
- 数据格式：JSON；图片上传使用 `multipart/form-data`
- 字段命名：camelCase
- 时间格式：UTC ISO 8601
- 实现基准：当前后端 `DalanbookV1Controller` 与 `DalanbookApiService`

发布页只保留图片、标题、正文和所属圈子。页面不再展示或提交地点，不展示话题、可见范围、预览和存草稿功能。

## 2. 页面字段与提交约定

| 页面字段 | 前端约束 | 提交字段 |
| --- | --- | --- |
| 图片 | 可选，最多 9 张；JPEG、PNG、WebP 或 GIF；单张不超过 10MB | `images` 和 `ratio` |
| 标题 | 必填，当前页面最多 30 字；后端最多 120 字 | `title` |
| 正文 | 必填，当前页面最多 1000 字；后端最多 10000 字 | `content` |
| 所属圈子 | 必填，只能选择当前用户已加入的圈子 | `circleId` |

当前页面的固定提交约定：

- `tag` 固定为 `经验`，后续增加独立帖子类型组件时再开放选择。
- `ratio` 以及每张图片的 `ratio` 当前固定为 `4/5`。
- 不提交 `topics`，后端按空列表处理。
- 不提交 `visibility`，后端按 `public` 处理。
- 地点不是当前后端 `CreatePostRequest` 的字段，不提交。

## 3. 获取可发布圈子

发布页复用圈子集合接口：

```http
GET /api/v1/circles?limit=50
```

前端只展示响应中 `isJoined=true` 的圈子。没有已加入圈子时，引导用户前往圈子集合页。完整字段见《圈子集合页 API 契约》。

后端发布接口仍会再次校验成员关系，不能只依赖前端过滤。

## 4. 上传图片

### 4.1 请求

```http
POST /api/v1/uploads
Authorization: Bearer <accessToken>
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 是 | 单张图片文件 |

选择多张图片时，前端对每个文件分别调用一次接口；最多并行上传到剩余的图片槽位，总数不超过 9 张。

### 4.2 响应

成功返回 `201 Created`：

```json
{
  "url": "https://example.com/uploads/2026/07/image.webp",
  "ossId": 10001,
  "contentType": "image/webp",
  "size": 245812
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `url` | `string` | 是 | 发布帖子时写入 `images[].url` 的可访问地址 |
| `ossId` | `string` | 是 | OSS 文件记录 ID，以字符串避免 JavaScript 大整数精度丢失 |
| `contentType` | `string` | 是 | 图片 MIME 类型 |
| `size` | `integer` | 是 | 文件字节数 |

前端展示使用 `url`，发布时仅提交 `ossId`，后端会校验该文件归属当前用户并动态生成访问地址。

## 5. 发布帖子

### 5.1 请求

```http
POST /api/v1/posts
Authorization: Bearer <accessToken>
Content-Type: application/json
```

当前页面提交示例：

```json
{
  "title": "我用 AI 整理周报一个月后的真实复盘",
  "content": "这里是帖子正文。",
  "circleId": "ai-tools",
  "images": [
    {
      "ossId": "1234567890123456789",
      "ratio": "4/5"
    }
  ],
  "ratio": "4/5",
  "tag": "经验"
}
```

### 5.2 请求字段

| 字段 | 类型 | 必填 | 后端约束 |
| --- | --- | --- | --- |
| `title` | `string` | 是 | 去除首尾空格后非空，最长 120 字符 |
| `content` | `string` | 是 | 去除首尾空格后非空，最长 10000 字符 |
| `circleId` | `string` | 是 | 已发布且当前用户已加入的圈子 ID |
| `images` | `ImageInput[]` | 否 | 0～9 张 |
| `images[].ossId` | `string` | 图片存在时是 | 图片上传接口返回的 OSS 文件 ID，必须归当前用户所有 |
| `images[].ratio` | `string` | 是 | `1/1`、`4/5`、`3/4`、`4/3` 或 `16/9` |
| `ratio` | `string` | 是 | 封面比例，取值同上 |
| `tag` | `string` | 是 | `经验`、`提问`、`测评`、`复盘`、`大神分享` 或 `清单` |
| `topics` | `string[]` | 否 | 最多 5 个，每个最长 20 字符；当前页面不传 |
| `visibility` | `string` | 否 | `circle` 表示圈内可见，其他值或不传均为公开；当前页面不传 |

### 5.3 响应

成功返回 `201 Created` 和完整 `Post`，结构与《帖子详情页 API 契约》的帖子详情一致。

前端收到响应后显示“发布成功”，并跳转：

```text
/posts/{response.id}
```

## 6. 错误响应

统一业务错误格式：

```json
{
  "code": "CIRCLE_MEMBERSHIP_REQUIRED",
  "message": "加入圈子后才能发布帖子",
  "details": null
}
```

| HTTP 状态码 | 错误码 | 使用场景 |
| --- | --- | --- |
| `401` | `UNAUTHORIZED` | 未登录上传图片或发布帖子 |
| `403` | `CIRCLE_MEMBERSHIP_REQUIRED` | 当前用户未加入所选圈子 |
| `404` | `CIRCLE_NOT_FOUND` | 所选圈子不存在或未发布 |
| `413` | `FILE_TOO_LARGE` | 单张图片超过 10MB |
| `422` | `EMPTY_FILE` | 上传文件为空 |
| `422` | `INVALID_FILE_TYPE` | 图片 MIME 类型不受支持 |
| `422` | `INVALID_POST_TAG` | 帖子标签不受支持 |
| `422` | `INVALID_IMAGE_RATIO` | 封面或图片比例不受支持 |
| `422` | `VALIDATION_FAILED` | 标题、正文、图片等字段不符合约束 |
| `429` | 统一限流响应 | 一小时发布超过 10 次或触发统一限流 |

## 7. 前端状态与交互

- 未登录选择图片或点击发布时，先打开登录引导，不发送接口请求。
- 图片上传期间展示“正在上传图片”，上传失败保留已经成功的图片并展示错误。
- 发布按钮只在上传或提交期间禁用；缺少标题、正文或圈子时，点击后提示具体原因。
- 图片可选，无图帖子以文本卡片展示。
- 发布期间按钮禁用，避免重复提交。
- 发布失败保留用户已经填写的内容，展示后端错误信息。
- 取消返回首页；当前不展示存草稿入口，也没有草稿 API。

## 8. 前端本地 Mock

`dalanbook-frontend/.env.local` 设置以下内容时，图片上传和发布帖子使用本地 Mock：

```dotenv
VITE_API_MODE=mock
```

Mock 会校验文件类型、大小、必填字段和圈子成员关系。发布成功后生成新的帖子详情数据，当前会话可直接跳转到 `/posts/{mockId}`。Mock 仅在 `npm run dev` 生效；正式构建和 `VITE_API_MODE=real` 始终请求真实后端。
