# 首页 API 契约

## 1. 文档信息

- 页面：普通用户端首页
- API 版本：v1
- Base URL：`/api/v1`
- 数据格式：`application/json`
- 字段命名：camelCase
- 时间格式：UTC ISO 8601，例如 `2026-07-16T08:00:00Z`

本页接口用于首页顶部分类、帖子瀑布流、我的圈子和圈子推荐卡片。

公开读取接口允许不登录访问。客户端已登录时应携带：

```http
Authorization: Bearer <accessToken>
```

后端可据此返回 `liked`、`joined` 等当前用户相关状态。

## 2. 核心概念

当前后端首页流只有一个筛选维度：

| 维度 | 参数 | 可选值 | 说明 |
| --- | --- | --- | --- |
| 内容分类 | `categoryId` | 由分类接口返回 | 对应推荐、职场成长、AI 工具等顶部分类 |

前端切换分类时，必须清空当前帖子列表和分页游标，并从第一页重新请求。

首页界面仍展示“推荐、关注、最新”三个频道入口，但当前后端接口没有 `channel` 参数，也没有关注流或独立排序能力。前端不得向接口传递未定义的 `channel` 参数；三个频道的差异化数据需要后端后续扩展接口后再接入。

## 3. 获取首页分类

### 3.1 请求

```http
GET /api/v1/home/categories
```

无需登录。

### 3.2 响应

```json
{
  "categories": [
    {
      "id": "recommend",
      "name": "推荐",
      "type": "system"
    },
    {
      "id": "career",
      "name": "职场成长",
      "type": "topic"
    },
    {
      "id": "ai",
      "name": "AI 工具",
      "type": "topic"
    }
  ],
  "defaultId": "recommend"
}
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `categories` | `Category[]` | 是 | 首页顶部分类列表，按展示顺序返回 |
| `defaultId` | `string` | 是 | 默认选中的分类 ID，必须存在于 `categories` 中 |
| `Category.id` | `string` | 是 | 稳定的分类标识，不使用分类名称作为请求参数 |
| `Category.name` | `string` | 是 | 前端展示名称 |
| `Category.type` | `system \| topic` | 是 | 系统入口或内容分类 |

分类 ID 一旦对前端发布，不应因展示名称变化而修改。

## 4. 获取首页帖子流

### 4.1 请求

```http
GET /api/v1/home/feed?categoryId=recommend&limit=20
```

### 4.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `categoryId` | `string` | 否 | `recommend` | 分类接口返回的分类 ID |
| `cursor` | `string` | 否 | 无 | 上一页返回的 `nextCursor`；第一页不传 |
| `limit` | `integer` | 否 | `20` | 每页数量，范围 1～40 |

当前实现固定查询 `status=published` 且 `visibility=public` 的帖子，并按 `(createdAt, id)` 倒序排列。`recommend` 和 `more` 属于系统分类，不增加圈子筛选；其他分类会先查询对应分类下的圈子，再筛选帖子。

未知的 `categoryId` 当前返回 `200` 和空列表，不返回分类错误。

`cursor` 是后端生成的不透明字符串，前端不得解析或自行构造。

### 4.3 响应

```json
{
  "items": [
    {
      "id": "post_1001",
      "title": "我用了 30 天 AI Agent，真正有用的是这 4 个场景",
      "tag": "经验",
      "cover": {
        "url": "https://example.com/posts/post_1001.webp",
        "ratio": "4/5",
        "blurhash": null
      },
      "circle": {
        "id": "ai-tools",
        "name": "AI 工具圈"
      },
      "author": {
        "id": "10001",
        "name": "林深",
        "avatarUrl": "https://example.com/users/10001.webp",
        "avatarColor": "#245BDB"
      },
      "useful": {
        "count": 328,
        "liked": false
      },
      "createdAt": "2026-07-16T08:00:00Z"
    }
  ],
  "nextCursor": "opaque_cursor_value",
  "hasMore": true
}
```

### 4.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | `FeedItem[]` | 是 | 当前页帖子；无数据时返回空数组 |
| `nextCursor` | `string \| null` | 是 | 下一页游标；没有下一页时为 `null` |
| `hasMore` | `boolean` | 是 | 是否还有下一页 |
| `FeedItem.id` | `string` | 是 | 帖子 ID |
| `FeedItem.title` | `string` | 是 | 帖子标题 |
| `FeedItem.tag` | `string \| null` | 是 | 帖子标签，无标签时为 `null` |
| `FeedItem.cover` | `Cover` | 是 | 首页卡片封面 |
| `FeedItem.circle` | `CircleBrief` | 是 | 帖子所属圈子 |
| `FeedItem.author` | `AuthorBrief` | 是 | 作者简要信息 |
| `FeedItem.useful` | `UsefulState` | 是 | 有用数及当前用户状态 |
| `FeedItem.createdAt` | `string` | 是 | 发布时间 |
| `Cover.url` | `string` | 是 | 可公开访问的 HTTPS 图片地址 |
| `Cover.ratio` | `1/1 \| 4/5 \| 3/4 \| 4/3 \| 16/9` | 是 | 封面宽高比 |
| `Cover.blurhash` | `string \| null` | 是 | 图片占位信息，未生成时为 `null` |
| `CircleBrief.id` | `string` | 是 | 圈子 ID |
| `CircleBrief.name` | `string` | 是 | 圈子名称 |
| `AuthorBrief.id` | `string` | 是 | 作者用户 ID |
| `AuthorBrief.name` | `string` | 是 | 作者昵称 |
| `AuthorBrief.avatarUrl` | `string \| null` | 是 | 头像地址 |
| `AuthorBrief.avatarColor` | `string \| null` | 是 | 无头像时使用的备用颜色 |
| `UsefulState.count` | `integer` | 是 | 有用数量，最小为 0 |
| `UsefulState.liked` | `boolean` | 是 | 当前用户是否已标记有用；未登录时为 `false` |

### 4.5 分页规则

- 首次请求不传 `cursor`。
- 加载下一页时原样传回 `nextCursor`。
- `hasMore=false` 后停止请求下一页。
- 新帖子插入不能导致已加载分页重复或漏项。
- 游标包含排序所需的 `createdAt` 和 `id`，但具体编码格式不属于契约内容。

## 5. 获取首页左侧导航数据

该接口返回后端快捷入口和“我的圈子”。推荐、关注、最新频道由首页前端固定维护，不使用 `shortcuts` 生成；为满足当前页面设计，首页也不渲染后端可能返回的消息入口。

### 5.1 请求

```http
GET /api/v1/home/left-nav
```

允许匿名访问。登录用户携带访问令牌后返回其加入的圈子。

### 5.2 响应

```json
{
  "shortcuts": [
    {
      "id": "home",
      "label": "首页",
      "icon": "home",
      "href": "/",
      "badge": null
    },
    {
      "id": "publish",
      "label": "发布",
      "icon": "plus",
      "href": "/publish",
      "badge": null
    }
  ],
  "myCircles": [
    {
      "id": "ai-tools",
      "name": "AI 工具圈",
      "avatarUrl": "https://example.com/circles/ai-tools.webp",
      "unread": 0
    }
  ]
}
```

### 5.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `shortcuts` | `Shortcut[]` | 是 | 后端快捷入口；匿名时包含首页和发布，登录后可能包含消息 |
| `Shortcut.id` | `string` | 是 | 快捷入口标识 |
| `Shortcut.label` | `string` | 是 | 展示名称 |
| `Shortcut.icon` | `string` | 是 | 图标标识 |
| `Shortcut.href` | `string` | 是 | 站内跳转地址 |
| `Shortcut.badge` | `integer \| null` | 是 | 未读数量或其他角标；无角标时为 `null` |
| `myCircles` | `MyCircle[]` | 是 | 用户加入的圈子；未登录时返回空数组 |
| `MyCircle.id` | `string` | 是 | 圈子 ID |
| `MyCircle.name` | `string` | 是 | 圈子名称 |
| `MyCircle.avatarUrl` | `string \| null` | 是 | 圈子头像或封面地址 |
| `MyCircle.unread` | `integer` | 是 | 圈子未读数量，暂未实现时固定返回 0 |

建议最多返回最近加入或最近活跃的 20 个圈子。

## 6. 获取首页圈子推荐

### 6.1 请求

```http
GET /api/v1/home/circle-recommend?categoryId=ai
```

### 6.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `categoryId` | `string` | 否 | `recommend` | 当前选中的首页分类 ID |

### 6.3 响应

```json
{
  "circle": {
    "id": "ai-tools",
    "name": "AI 工具圈",
    "desc": "分享 AI 工具、自动化流程与真实效率经验",
    "membersText": "12.8 万人正在讨论",
    "memberCount": 128000,
    "joined": false
  },
  "insertAfterIndex": 6
}
```

没有合适的推荐圈子时：

```json
{
  "circle": null,
  "insertAfterIndex": 6
}
```

### 6.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `circle` | `CircleRecommendation \| null` | 是 | 推荐圈子，无推荐时为 `null` |
| `insertAfterIndex` | `integer` | 是 | 推荐卡片插入到第几个帖子之后，从 0 开始计数 |
| `CircleRecommendation.id` | `string` | 是 | 圈子 ID |
| `CircleRecommendation.name` | `string` | 是 | 圈子名称 |
| `CircleRecommendation.desc` | `string` | 是 | 圈子简介 |
| `CircleRecommendation.membersText` | `string` | 是 | 已格式化的成员数量文案 |
| `CircleRecommendation.memberCount` | `integer` | 是 | 原始成员数量 |
| `CircleRecommendation.joined` | `boolean` | 是 | 当前用户是否已加入；未登录时为 `false` |

## 7. HTTP 状态码与错误响应

| HTTP 状态码 | 错误码 | 使用场景 |
| --- | --- | --- |
| `400` | `INVALID_CURSOR` | 游标格式错误或已失效 |
| `400` | 框架校验错误 | `limit` 小于 1 或大于 40 |
| `500` | 服务端错误 | 未处理的服务端异常 |

`DalanApiException` 的实际错误响应格式：

```json
{
  "code": "INVALID_CURSOR",
  "message": "cursor 无效或已失效",
  "details": null
}
```

前端行为约定：

- `INVALID_CURSOR`：清空当前列表并重新请求第一页。
- 网络错误和 5xx：保留已有列表并展示重试入口。
- 首屏加载失败：展示首页错误态，不回退到 Mock 数据。

## 8. 前端缓存与刷新约定

建议 React Query Key：

```text
["home", "categories"]
["home", "feed", categoryId, userId]
["home", "left-nav", userId]
["home", "circle-recommend", categoryId, userId]
```

- 分类数据可缓存 10 分钟。
- 我的圈子可缓存 1 分钟，登录状态变化时立即失效。
- 帖子流可缓存 30 秒，并使用无限分页。当前首页 UI 的 `channel` 不影响请求参数或缓存键。
- 圈子推荐可缓存 5 分钟，加入或退出圈子后立即失效。

## 9. 本期范围

本期首页前端实现包括：

- 分类加载与切换。
- 推荐、关注、最新频道入口展示；当前三者尚未对应独立后端数据源。
- 帖子瀑布流及游标分页。
- 我的圈子加载。
- 圈子推荐卡片加载与插入。
- 加载中、空数据、失败和重试状态。

以下能力不包含在本期首页 API 实现中，后续单独设计：

- 搜索结果页和搜索联想。
- 消息通知列表及未读提醒。
- 推荐曝光与点击埋点。
- 首页内容管理端配置。

## 10. 前端本地 Mock 模式

后端开发库暂时没有 v1 首页数据时，前端可在 `dalanbook-frontend/.env.local` 中启用：

```dotenv
VITE_API_MODE=mock
```

- Mock 开关由前端 API 层统一管理，只在 `npm run dev` 的开发服务器中生效。
- `npm run build` 和未显式开启 Mock 的环境始终请求真实 `/api/v1/home/*` 接口。
- Mock 适配器返回与本契约相同的 TypeScript 数据结构，页面组件和 React Query 不区分数据来源。
- 前后端联调时将该值改为 `real`，或删除 `.env.local` 后重启开发服务器。
- `.env.local` 已被 Git 忽略；仓库通过 `.env.example` 提供开关示例。
