# 帖子详情页 API 契约

## 1. 文档信息

- 页面：普通用户端帖子详情页 `/posts/{id}`
- API 版本：v1
- Base URL：`/api/v1`
- 数据格式：`application/json`
- 字段命名：camelCase
- 时间格式：UTC ISO 8601
- 实现基准：当前后端 `DalanbookV1Controller` 与 `DalanbookApiService`

本页包含帖子详情、点赞、收藏、评论分页、发表评论/回复和删除自己的评论。帖子详情页没有“有用”状态或“有用数”的概念。作者关注、分享和“同圈子推荐”目前没有归入本页后端 API。

## 2. 获取帖子详情

### 2.1 请求

```http
GET /api/v1/posts/{id}
```

公开帖子允许匿名访问。圈内可见帖子要求当前用户已经加入所属圈子。

### 2.2 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 帖子 ID，传输时进行 URL 编码 |

### 2.3 响应

```json
{
  "id": "p_10001",
  "title": "我用了 30 天 AI Agent，真正有用的是这 4 个场景",
  "content": "帖子正文，支持换行但当前不是富文本 HTML",
  "images": [
    {
      "url": "https://example.com/posts/cover.webp",
      "ratio": "4/5"
    }
  ],
  "cover": "https://example.com/posts/cover.webp",
  "ratio": "4/5",
  "tag": "经验",
  "topics": [
    {
      "id": "topic-10001",
      "slug": "ai-tools",
      "name": "AI 工具",
      "description": "AI 工具相关经验与讨论",
      "postCount": 120,
      "createdAt": "2026-07-01T08:00:00Z"
    }
  ],
  "circle": {
    "id": "ai-tools",
    "name": "AI 工具圈"
  },
  "author": {
    "id": "user-10001",
    "name": "林深",
    "avatarUrl": "https://example.com/avatar.webp",
    "avatarColor": "#245BDB"
  },
  "likeCount": 126,
  "commentCount": 18,
  "favoriteCount": 84,
  "isLiked": false,
  "isFavorited": false,
  "createdAt": "2026-07-16T08:30:00Z"
}
```

### 2.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 帖子 ID |
| `title` | `string` | 是 | 帖子标题 |
| `content` | `string` | 是 | 纯文本正文 |
| `images` | `Image[]` | 是 | 帖子图片，最多 9 张 |
| `images[].url` | `string` | 是 | 图片地址 |
| `images[].ratio` | `string` | 是 | 图片比例：`1/1`、`4/5`、`3/4`、`4/3` 或 `16/9` |
| `cover` | `string` | 是 | 封面地址，通常为第一张图片 |
| `ratio` | `string` | 是 | 封面比例 |
| `tag` | `string` | 是 | 帖子标签 |
| `topics` | `Topic[]` | 是 | 关联话题 |
| `circle` | `object` | 是 | 所属圈子的 ID 和名称 |
| `author` | `object` | 是 | 作者信息；`avatarUrl` 可为空 |
| `likeCount` | `integer` | 是 | 点赞数量 |
| `commentCount` | `integer` | 是 | 未删除评论及回复总数 |
| `favoriteCount` | `integer` | 是 | 收藏数量 |
| `isLiked` | `boolean` | 是 | 当前用户是否点赞；匿名时为 `false` |
| `isFavorited` | `boolean` | 是 | 当前用户是否收藏；匿名时为 `false` |
| `createdAt` | `string` | 是 | 发布时间 |

当前后端响应可能暂时包含历史字段 `usefulCount` 和 `isUseful`。前端不会读取或展示这两个字段；后端按本契约调整时应将其从帖子详情 DTO 中移除。

## 3. 设置点赞或收藏状态

### 3.1 请求

```http
POST /api/v1/posts/{id}/reactions/{type}
Authorization: Bearer <accessToken>
Content-Type: application/json
```

帖子详情页只允许 `type=like` 或 `type=favorite`。前端不调用 `/posts/{id}/useful`，也不会向该接口传递 `type=useful`。

```json
{
  "active": true
}
```

### 3.2 响应

```json
{
  "type": "favorite",
  "count": 85,
  "active": true
}
```

该接口同样是幂等状态设置。

## 4. 获取评论列表

### 4.1 请求

```http
GET /api/v1/posts/{id}/comments?limit=50
```

下一页请求：

```http
GET /api/v1/posts/{id}/comments?cursor=opaque_cursor_value&limit=50
```

### 4.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `cursor` | `string` | 否 | 无 | 上一页返回的不透明游标 |
| `limit` | `integer` | 否 | `20` | 顶级评论每页数量，范围 1～50；详情页当前传 50 |

### 4.3 响应

```json
{
  "items": [
    {
      "id": "cm_10001",
      "parentId": null,
      "author": {
        "id": "user-10002",
        "name": "周航",
        "avatarUrl": null,
        "avatarColor": "#5E6B7F"
      },
      "content": "这个方法很实用。",
      "deleted": false,
      "isMine": false,
      "createdAt": "2026-07-16T09:00:00Z",
      "replies": [
        {
          "id": "cm_10002",
          "parentId": "cm_10001",
          "author": {
            "id": "user-10001",
            "name": "林深",
            "avatarUrl": null,
            "avatarColor": "#245BDB"
          },
          "content": "谢谢，后面会继续补充。",
          "deleted": false,
          "isMine": false,
          "createdAt": "2026-07-16T09:10:00Z",
          "replies": []
        }
      ]
    }
  ],
  "nextCursor": null,
  "hasMore": false
}
```

顶级评论按 `(createdAt, id)` 倒序；每个顶级评论的回复按 `(createdAt, id)` 正序。已删除评论仍返回原位置，但 `deleted=true`、`content` 为空。评论最多两级。

## 5. 发表评论或回复

### 5.1 请求

```http
POST /api/v1/posts/{id}/comments
Authorization: Bearer <accessToken>
Content-Type: application/json
```

顶级评论：

```json
{
  "content": "这个方法很实用。"
}
```

回复顶级评论：

```json
{
  "content": "我也遇到过同样的问题。",
  "parentId": "cm_10001"
}
```

| 字段 | 类型 | 必填 | 后端约束 |
| --- | --- | --- | --- |
| `content` | `string` | 是 | 去除首尾空格后非空，最长 1000 字符 |
| `parentId` | `string` | 否 | 只能指向当前帖子未删除的顶级评论 |

成功返回 `201 Created` 和新建的 `Comment`。前端清空输入框、增加本地评论数并刷新评论列表。

## 6. 删除自己的评论

### 6.1 请求

```http
DELETE /api/v1/comments/{id}
Authorization: Bearer <accessToken>
```

### 6.2 响应

```json
{
  "deleted": true
}
```

后端采用软删除：保留评论位置，将状态标记为已删除并清空正文。只能删除当前登录用户自己的评论。

## 7. 错误响应

统一业务错误格式：

```json
{
  "code": "POST_NOT_FOUND",
  "message": "帖子不存在",
  "details": null
}
```

| HTTP 状态码 | 错误码 | 使用场景 |
| --- | --- | --- |
| `400` | `INVALID_CURSOR` | 评论分页游标无效或已失效 |
| `401` | `UNAUTHORIZED` | 未登录调用互动、发表评论或删除评论接口 |
| `403` | `CIRCLE_MEMBERSHIP_REQUIRED` | 未加入圈子访问圈内可见帖子 |
| `403` | `COMMENT_DELETE_FORBIDDEN` | 删除他人的评论 |
| `404` | `POST_NOT_FOUND` | 帖子不存在或未发布 |
| `404` | `COMMENT_NOT_FOUND` | 回复目标或删除目标不存在 |
| `422` | `INVALID_REACTION_TYPE` | 互动类型不在允许范围内 |
| `422` | `REPLY_DEPTH_EXCEEDED` | 尝试回复二级评论 |
| `422` | `VALIDATION_FAILED` | 请求体字段不符合约束 |
| `429` | 统一限流响应 | 互动、评论频率超过后端限制 |

## 8. 前端缓存与状态

React Query Key：

```text
["dalanbook", "post", postId, "comments"]
```

- 帖子详情由 TanStack Router Loader 请求，路由参数变化时重新加载。
- 评论当前一次请求最多 50 条顶级评论；API 已保留 `cursor` 和 `limit` 参数，后续可直接升级为无限分页。
- 点赞和收藏按钮先乐观更新，再以服务端返回的最终状态为准；失败时回滚。
- 发表评论、回复或删除后刷新评论缓存，并同步详情页本地 `commentCount`。
- 未登录进行写操作时，前端先打开登录引导，不发送写请求。

## 9. 前端本地 Mock

`dalanbook-frontend/.env.local` 设置以下内容时，帖子详情、互动、评论分页、发表评论/回复和删除评论使用同结构本地 Mock：

```dotenv
VITE_API_MODE=mock
```

Mock 帖子由首页及圈子页的本地帖子数据扩展生成，因此 `p1` 等卡片可以直接打开详情。Mock 点赞和收藏写入幂等，评论支持两级结构和软删除。Mock 不提供“有用”状态或计数。Mock 仅在 `npm run dev` 生效；正式构建和 `VITE_API_MODE=real` 始终请求真实后端。
