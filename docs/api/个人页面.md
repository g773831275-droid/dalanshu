# 个人页面 API 契约

## 1. 页面范围

个人页面路由为 `/u/{id}`：

- `/u/me`：当前登录用户的个人页；
- `/u/{userId}`：其他用户的公开主页；
- 本人可查看“笔记、收藏、点赞”、加入的圈子并编辑资料；
- 其他用户主页只展示公开资料和公开笔记；
- 收藏、点赞和加入圈子均为本人私有数据，不向其他用户开放。

分享由浏览器 `Web Share API` 或复制链接完成，不需要后端接口。私信属于后续聊天模块，不包含在本契约中。

## 3. 用户资料

### 3.1 获取本人资料摘要

```http
GET /api/v1/me/summary
Authorization: Bearer <accessToken>
clientid: <clientId>
```

### 3.2 获取他人公开资料

```http
GET /api/v1/users/{id}
```

本人摘要响应使用 `{ "user": UserProfile, "unreadCount": number }`；他人资料接口直接返回 `UserProfile`。页面使用的 `UserProfile` 结构如下：

```json
{
    "id": "4785734088776482816",
    "nickname": "林深",
    "avatar": "https://example.com/avatar.jpg",
    "bio": "AI 工具重度用户，每周复盘一次。",
    "gender": "unknown",
    "location": "北京 · 海淀",
    "followerCount": 4200,
    "followingCount": 86,
    "postCount": 128,
    "isFollowing": false,
    "createdAt": "2024-03-01T08:00:00Z"
}
```

| 字段             | 类型                                 | 必填 | 说明                                                |
| ---------------- | ------------------------------------ | ---- | --------------------------------------------------- |
| `id`             | `string`                             | 是   | 用户 ID；JSON 中禁止使用 number，避免长整型精度丢失 |
| `nickname`       | `string`                             | 是   | 昵称                                                |
| `avatar`         | `string \| null`                     | 是   | 头像地址；无头像返回 `null`                         |
| `bio`            | `string`                             | 是   | 个人简介；未填写返回空字符串                        |
| `gender`         | `unknown \| male \| female \| other` | 是   | 性别                                                |
| `location`       | `string`                             | 是   | 页面展示地域；未填写返回空字符串                    |
| `followerCount`  | `integer`                            | 是   | 粉丝数                                              |
| `followingCount` | `integer`                            | 是   | 关注数                                              |
| `postCount`      | `integer`                            | 是   | 已发布且可见的笔记数                                |
| `isFollowing`    | `boolean`                            | 是   | 当前登录用户是否关注该用户；未登录固定为 `false`    |
| `createdAt`      | `string \| null`                     | 是   | UTC 注册时间                                        |

本人访问 `/u/me` 时前端调用 `GET /api/v1/me/summary`，不会把字符串 `me` 传给只接受数字 ID 的 `/users/{id}`。

## 4. 个人内容列表

个人页的三种内容复用同一个卡片结构和游标分页规则。

### 4.1 获取本人的笔记、收藏或点赞

```http
GET /api/v1/me/posts?type=published&cursor=&limit=40
Authorization: Bearer <accessToken>
clientid: <clientId>
```

| 参数     | 类型                             | 必填 | 默认值      | 说明                   |
| -------- | -------------------------------- | ---- | ----------- | ---------------------- |
| `type`   | `published \| favorite \| liked` | 否   | `published` | 已发布笔记、收藏、点赞 |
| `cursor` | `string`                         | 否   | -           | 上一页返回的游标       |
| `limit`  | `integer`                        | 否   | `20`        | 范围 `1–40`            |

### 4.2 获取其他用户的公开笔记

```http
GET /api/v1/users/{id}/posts?cursor=&limit=12
```

该接口只返回目标用户已发布且当前访问者可见的笔记，不接受 `tab` 参数。

### 4.3 Response

```json
{
    "items": [
        {
            "id": "p_01",
            "title": "我用了 30 天 AI Agent",
            "tag": "经验",
            "cover": {
                "url": "https://example.com/post-cover.jpg",
                "ratio": "4/5"
            },
            "circle": {
                "id": "c_ai",
                "name": "AI 工具圈"
            },
            "author": {
                "id": "4785734088776482816",
                "name": "林深",
                "avatarUrl": null,
                "avatarColor": "#245BDB"
            },
            "useful": {
                "count": 328,
                "liked": false
            },
            "createdAt": "2026-07-16T08:00:00Z"
        }
    ],
    "nextCursor": "eyJjcmVhdGVkQXQiOiIuLi4ifQ",
    "hasMore": true
}
```

列表按关系时间倒序排列：

- `published`：按帖子 `(createdAt, id)` 倒序；
- `favorite`：按收藏关系 `(createdAt, postId)` 倒序；
- `liked`：按点赞关系 `(createdAt, postId)` 倒序。

取消收藏或取消点赞后，对应内容不再出现在下一次请求中。已删除、审核不可见或无权限访问的帖子不得返回。

## 5. 本人加入的圈子

复用圈子模块已有接口：

```http
GET /api/v1/circles/mine?ownedOnly=false
Authorization: Bearer <accessToken>
clientid: <clientId>
```

返回 `Circle[]`。该接口只用于本人页面，不新增“查看其他用户加入圈子”的接口。

## 6. 关注或取消关注用户

```http
PUT /api/v1/users/{id}/follow
Authorization: Bearer <accessToken>
clientid: <clientId>
Content-Type: application/json
```

### Request

```json
{
    "following": true
}
```

`following=true` 表示关注，`false` 表示取消关注。接口必须幂等。

### 200 Response

响应返回更新后的完整 `UserProfile`，页面直接用它刷新关注状态和粉丝数：

```json
{
    "id": "4785734088776482816",
    "nickname": "林深",
    "avatar": null,
    "bio": "AI 工具重度用户，每周复盘一次。",
    "gender": "unknown",
    "location": "北京 · 海淀",
    "followerCount": 4201,
    "followingCount": 86,
    "postCount": 128,
    "isFollowing": true,
    "createdAt": "2024-03-01T08:00:00Z"
}
```

后端应在事务内同时维护关注关系、目标用户粉丝数和当前用户关注数。关注成功时生成 `user_follow` 通知；取消关注不生成通知。禁止关注自己。

## 7. 查看和编辑本人资料

### 7.1 获取可编辑资料

```http
GET /api/v1/me/profile
```

### 7.2 更新资料

```http
PUT /api/v1/me/profile
Content-Type: application/json
```

## 8. 错误响应

```json
{
    "code": "USER_NOT_FOUND",
    "message": "用户不存在"
}
```

| HTTP 状态 | `code`                      | 场景                         |
| --------- | --------------------------- | ---------------------------- |
| `400`     | `INVALID_CURSOR`            | 游标格式无效                 |
| `401`     | `UNAUTHORIZED`              | 本人数据接口未登录或令牌失效 |
| `403`     | `PROFILE_CONTENT_FORBIDDEN` | 请求了无权查看的私有内容     |
| `404`     | `USER_NOT_FOUND`            | 用户不存在                   |
| `409`     | `CANNOT_FOLLOW_SELF`        | 关注自己                     |
| `422`     | `VALIDATION_FAILED`         | 参数或资料字段校验失败       |

## 9. 前端实现

- `src/lib/userApi.ts`：用户资料、三类内容列表、关注操作和页面模型转换；
- `src/lib/authApi.mock.ts`：补齐本人资料查看与编辑 Mock；
- `src/routes/u.$id.tsx`：使用 React Query 接入资料、列表、圈子和关注操作；
- 他人主页只渲染“笔记”标签，本人主页才渲染“收藏”和“点赞”；
- API 封装支持游标参数；当前页面每个标签请求首批最多 40 条内容。
