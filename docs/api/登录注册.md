# 登录注册页与登录弹窗 API 契约

## 1. 文档信息

- 页面：独立登录注册页 `/auth`
- 组件：全局登录注册弹窗 `AuthModal`
- API 版本：v1
- Base URL：`/api/v1/auth`
- 数据格式：`application/json`
- 字段命名：请求 camelCase；令牌响应使用 snake_case
- 实现基准：当前后端 `AuthController`、`CaptchaController` 与 `DalanbookV1Controller`

独立页面和全局弹窗共用同一套前端 API。前端只展示手机号密码登录与手机号短信验证码注册，不展示邮箱、微信、Apple、Google 或其他第三方登录方式。邮箱验证码仅为后台兼容的密码找回能力，不属于用户端认证流程。

## 2. 手机号认证流程

登录：

```text
获取图形验证码 -> 手机号 + 密码登录 -> 保存令牌 -> 获取当前用户 -> 进入目标页面
```

注册：

```text
输入手机号 -> 获取短信验证码 -> 手机号 + 短信验证码 + 密码注册并自动登录 -> 保存令牌 -> 获取当前用户 -> 进入目标页面
```

登录弹窗成功后关闭弹窗，并跳转到触发登录时记录的 `redirect`；独立页面成功后跳转到 URL 查询参数中的 `redirect`，缺省返回首页。

## 3. 获取图形验证码

```http
GET /api/v1/auth/code
```

验证码开启时，响应的 `data` 包含 `captchaEnabled`、`uuid` 和 `img`；前端收到没有 `data:` 前缀的 `img` 时，按 GIF Base64 补充。验证码关闭时仅返回 `captchaEnabled: false`。图形验证码只用于密码登录。

## 4. 获取短信验证码

```http
GET /api/v1/auth/sms/code?phonenumber=13800138000
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `phonenumber` | `string` | 是 | 中国大陆 11 位手机号，`1[3-9]xxxxxxxxx` |

接口按手机号限制每分钟一次，并受短信服务的每日上限约束。成功后响应 `{ "code": 200, "data": null }`；生产环境不得回显验证码。验证码默认有效期 5 分钟，注册成功后立即失效。

## 5. 手机号密码登录

```http
POST /api/v1/auth/login
Content-Type: application/json
clientid: e5cd7e4891bf95d1d19206ce24a7b32e
```

```json
{
  "account": "13800138000",
  "password": "user-password",
  "clientId": "e5cd7e4891bf95d1d19206ce24a7b32e",
  "grantType": "password",
  "uuid": "captcha_uuid",
  "code": "abcd"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `account` | `string` | 是 | 11 位手机号 |
| `password` | `string` | 是 | 前端 6～64 位；后端校验 5～30 位 |
| `clientId` | `string` | 是 | Web 客户端 ID |
| `grantType` | `string` | 是 | 固定 `password` |
| `uuid` | `string` | 条件必填 | 图形验证码开启时必填 |
| `code` | `string` | 条件必填 | 图形验证码开启时必填 |

## 6. 手机号注册

```http
POST /api/v1/auth/register
Content-Type: application/json
clientid: e5cd7e4891bf95d1d19206ce24a7b32e
```

```json
{
  "phonenumber": "13800138000",
  "smsCode": "123456",
  "password": "user-password",
  "clientId": "e5cd7e4891bf95d1d19206ce24a7b32e",
  "grantType": "password"
}
```

| 字段 | 类型 | 必填 | 后端约束 |
| --- | --- | --- | --- |
| `phonenumber` | `string` | 是 | 中国大陆 11 位手机号，当前租户内不能重复 |
| `smsCode` | `string` | 是 | 6 位短信验证码，校验成功后立即失效 |
| `password` | `string` | 是 | 8～30 位 |
| `clientId` | `string` | 是 | Web 客户端 ID |
| `grantType` | `string` | 是 | 固定 `password` |

成功后后端创建账号并直接返回与登录相同的令牌响应，不需要再次请求登录接口。

## 7. 获取当前用户

```http
GET /api/v1/auth/me
Authorization: Bearer <accessToken>
```

前端认证状态只保存 `id`、`nickname -> name` 和可选 `avatar`。

## 8. 刷新令牌与退出

访问令牌失效并返回 `401` 时，前端使用 `POST /api/v1/auth/refresh` 与 `refreshToken` 换取新令牌；刷新令牌采用 rotation，旧令牌成功使用后立即失效。退出登录调用 `POST /api/v1/auth/logout`，无论请求是否成功，前端最终都会清除本地令牌和用户状态。

## 9. 错误与前端处理

| 场景 | 前端处理 |
| --- | --- |
| 手机号格式、密码长度或确认密码错误 | 表单字段下方显示本地校验信息，不发送请求 |
| 图形验证码缺失或错误 | 显示接口信息并刷新图形验证码 |
| 短信验证码错误或过期 | 保留注册表单内容，显示接口信息 |
| 手机号已经注册 | 保留注册表单内容，提示切换登录 |
| 获取短信验证码失败 | 保留注册表单内容，显示接口信息 |
| 登录失败 | 保留手机号并刷新图形验证码 |
| `401` 且存在刷新令牌 | 自动刷新令牌并重试原请求一次 |

## 10. 前端本地 Mock

`dalanbook-frontend/.env.local` 设置以下内容时，图形验证码、短信验证码、登录、注册、当前用户和退出登录使用本地 Mock：

```dotenv
VITE_API_MODE=mock
```

Mock 约定：

- 图形验证码关闭。
- 注册短信验证码固定为 `123456`，点击获取后自动填入。
- 演示手机号：`13800138000`。
- 演示密码：`dalanbook123`。
- 新注册账号在当前开发会话内可以立即登录。

Mock 仅在 `npm run dev` 生效；正式构建和 `VITE_API_MODE=real` 始终请求真实后端。
