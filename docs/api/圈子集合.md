# 圈子集合页 API 契约

## 1. 文档信息

- 页面：普通用户端圈子集合页 `/circles`
- API 版本：v1
- Base URL：`/api/v1`
- 数据格式：`application/json`
- 字段命名：camelCase
- 时间格式：UTC ISO 8601
- 实现基准：当前后端 `DalanbookV1Controller` 与 `DalanbookApiService`

本页包含公开圈子列表、分类筛选、我的圈子和加入/退出圈子能力。创建圈子接口仍作为后端公共能力保留，但圈子集合页当前不展示创建入口。

## 2. 页面筛选约定

普通列表支持 `category` 精确筛选；输入关键词时，页面改用后端圈子搜索接口。页面行为如下：

- “全部”分类不传 `category`。
- 其他分类传展示名称，例如 `category=AI 工具`。
- 搜索框把去除首尾空格后的关键词作为 `q` 发送到 `/search/circles`，匹配圈子名称、简介和标签。
- 切换分类时清空已有分页数据，从第一页重新请求。
- 分类选项当前由前端固定维护，后端没有圈子分类枚举接口。

## 3. 获取公开圈子列表

### 3.1 请求

```http
GET /api/v1/circles?category=AI%20%E5%B7%A5%E5%85%B7&limit=8
```

### 3.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `category` | `string` | 否 | 无 | 圈子分类展示名称，精确匹配 |
| `cursor` | `string` | 否 | 无 | 上一页返回的不透明游标 |
| `limit` | `integer` | 否 | `20` | 每页数量，范围 1～50 |

未知分类当前返回 `200` 和空列表。

### 3.3 响应

```json
{
  "items": [
    {
      "id": "ai-tools",
      "name": "AI 工具圈",
      "cover": "https://example.com/circles/ai-tools.webp",
      "desc": "分享 AI 工具、自动化流程与真实效率经验",
      "category": "AI 工具",
      "tags": ["AI", "效率", "自动化"],
      "memberCount": 128000,
      "postCount": 3240,
      "isJoined": false,
      "isOwner": false,
      "ownerId": "10001",
      "createdAt": "2026-07-16T07:00:00Z"
    }
  ],
  "nextCursor": "opaque_cursor_value",
  "hasMore": true
}
```

### 3.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | `Circle[]` | 是 | 当前页圈子 |
| `nextCursor` | `string \| null` | 是 | 下一页游标，无下一页时为 `null` |
| `hasMore` | `boolean` | 是 | 是否还有下一页 |
| `Circle.id` | `string` | 是 | 圈子 ID |
| `Circle.name` | `string` | 是 | 圈子名称 |
| `Circle.cover` | `string` | 是 | 圈子封面地址 |
| `Circle.desc` | `string` | 是 | 圈子简介 |
| `Circle.category` | `string` | 是 | 分类展示名称 |
| `Circle.tags` | `string[]` | 是 | 圈子标签 |
| `Circle.memberCount` | `integer` | 是 | 成员数量 |
| `Circle.postCount` | `integer` | 是 | 帖子数量 |
| `Circle.isJoined` | `boolean` | 是 | 当前用户是否已加入；匿名时为 `false` |
| `Circle.isOwner` | `boolean` | 是 | 当前用户是否为圈主；匿名时为 `false` |
| `Circle.ownerId` | `string` | 是 | 圈主用户 ID |
| `Circle.createdAt` | `string` | 是 | 创建时间 |

当前后端只返回 `status=published` 的圈子，按 `(createdAt, id)` 倒序排列。

## 3.5 搜索公开圈子

```http
GET /api/v1/search/circles?q=AI&category=AI%20%E5%B7%A5%E5%85%B7&limit=8
```

`q` 必填，长度 1～100；`category`、`cursor` 和 `limit` 与公开圈子列表含义一致。响应结构与公开圈子列表相同，仅返回已发布圈子，并在名称、简介和标签中进行关键词匹配。接口允许匿名访问。

## 4. 获取我创建的圈子

### 4.1 请求

```http
GET /api/v1/circles/mine?ownedOnly=true
Authorization: Bearer <accessToken>
```

### 4.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `ownedOnly` | `boolean` | 否 | `false` | `true` 返回我创建的圈子；`false` 返回我加入的圈子 |

### 4.3 响应

响应体为 `Circle[]`，不分页。未登录返回 `401`。

圈子集合页只在已登录时请求该接口，并固定传 `ownedOnly=true` 展示“我创建的”。公开列表中的 `isJoined=true` 用于展示“你已加入”。

## 5. 创建圈子

> 当前圈子集合页不调用本节接口，也不展示“创建圈子”按钮；本节仅保留后端能力契约，供后续独立入口使用。

### 5.1 请求

```http
POST /api/v1/circles
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "name": "独立开发者圈",
  "cover": "https://example.com/covers/indie.webp",
  "desc": "交流独立产品从想法、开发到增长的真实实践",
  "category": "AI 工具",
  "tags": ["开发", "副业", "SaaS"]
}
```

### 5.2 请求约束

| 字段 | 类型 | 必填 | 后端约束 |
| --- | --- | --- | --- |
| `name` | `string` | 是 | 1～80 字符，去除首尾空格后不能重复 |
| `cover` | `string` | 是 | 最长 500 字符 |
| `desc` | `string` | 是 | 最长 300 字符 |
| `category` | `string` | 是 | 最长 40 字符 |
| `tags` | `string[]` | 否 | 最多 10 个，每个最长 20 字符 |

成功返回 `201 Created` 和新建的 `Circle`。创建者自动成为圈主和成员，`memberCount=1`、`postCount=0`、`isJoined=true`、`isOwner=true`。

## 6. 加入或退出圈子

### 6.1 请求

```http
PUT /api/v1/circles/{id}/membership
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "joined": true
}
```

`joined=true` 表示加入，`joined=false` 表示退出。成功返回更新后的 `Circle`。圈主不能退出自己的圈子。

## 7. 错误响应

后端业务错误格式：

```json
{
  "code": "CIRCLE_NAME_EXISTS",
  "message": "圈子名称已存在",
  "details": null
}
```

| HTTP 状态码 | 错误码 | 使用场景 |
| --- | --- | --- |
| `400` | `INVALID_CURSOR` | 游标无效或已失效 |
| `401` | `UNAUTHORIZED` 或统一认证响应 | 未登录访问我的圈子、创建或成员接口 |
| `404` | `CIRCLE_NOT_FOUND` | 圈子不存在或未发布 |
| `409` | `CIRCLE_NAME_EXISTS` | 创建圈子时名称重复 |
| `409` | `OWNER_CANNOT_LEAVE` | 圈主尝试退出自己的圈子 |
| `422` | `VALIDATION_FAILED` | 请求参数不符合约束 |

## 8. 前端缓存与分页

React Query Key：

```text
["dalanbook", "circles", "collection", category]
["dalanbook", "circles", "mine"]
```

- 公开列表使用无限分页，每页请求 8 个圈子。
- `hasMore=true` 时展示“加载更多圈子”。
- 加载下一页时原样传递 `nextCursor`，前端不得解析游标。
- 创建圈子或修改成员状态后，失效 `["dalanbook", "circles"]` 前缀下的缓存。
- 网络错误保留已加载内容；下一页失败时展示重试按钮。

## 9. 前端本地 Mock

`dalanbook-frontend/.env.local` 设置以下内容时，圈子集合、我的圈子、创建和成员操作使用同结构本地 Mock：

```dotenv
VITE_API_MODE=mock
```

Mock 仅在 `npm run dev` 生效；正式构建和 `VITE_API_MODE=real` 始终请求真实后端。
