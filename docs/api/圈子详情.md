# 圈子详情页 API 契约

## 1. 文档信息

- 页面：普通用户端圈子详情页 `/circles/{id}`
- API 版本：v1
- Base URL：`/api/v1`
- 数据格式：`application/json`
- 字段命名：camelCase
- 时间格式：UTC ISO 8601
- 实现基准：当前后端 `DalanbookV1Controller` 与 `DalanbookApiService`

本页由圈子资料、圈子置顶内容、圈内帖子游标分页以及加入/退出圈子四个后端能力组成。页面不展示圈子通知按钮。

> 实现状态：置顶内容接口与前端调用已定义，当前后端尚未实现；其余接口已联调。

## 2. 页面内容分类约定

圈子详情页只保留“推荐”和“最新”两个内容标签：

| 页面标签 | 前端 key | 当前实现 |
| --- | --- | --- |
| 推荐 | `recommend` | 将前端已经加载的帖子按 `useful.count` 从高到低排列 |
| 最新 | `latest` | 保持后端返回顺序，即按 `(createdAt, id)` 倒序 |

当前后端圈内帖子接口没有 `sort` 参数，因此标签切换不重新请求，也不向接口传递标签值。“推荐”只是当前已加载数据内的临时排序，并非全量服务端推荐结果。后端增加推荐排序能力后，应扩展接口参数并把标签加入查询缓存键。

## 3. 获取圈子详情

### 3.1 请求

```http
GET /api/v1/circles/{id}
```

该接口允许匿名访问。登录用户携带访问令牌时，响应中的 `isJoined` 和 `isOwner` 反映当前用户状态。

### 3.2 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 圈子 ID，传输时进行 URL 编码 |

### 3.3 响应

```json
{
  "id": "ai-tools",
  "name": "AI 工具圈",
  "cover": "https://example.com/circles/ai-tools.webp",
  "desc": "分享 AI 工具、自动化流程与真实效率经验",
  "category": "AI 工具",
  "tags": ["AI", "效率", "自动化"],
  "memberCount": 128000,
  "postCount": 3240,
  "isJoined": true,
  "isOwner": false,
  "ownerId": "10001",
  "createdAt": "2026-07-16T07:00:00Z"
}
```

### 3.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 圈子 ID |
| `name` | `string` | 是 | 圈子名称 |
| `cover` | `string` | 是 | 圈子封面地址 |
| `desc` | `string` | 是 | 圈子简介 |
| `category` | `string` | 是 | 圈子所属分类 |
| `tags` | `string[]` | 是 | 圈子标签 |
| `memberCount` | `integer` | 是 | 当前成员数量 |
| `postCount` | `integer` | 是 | 已发布帖子数量 |
| `isJoined` | `boolean` | 是 | 当前用户是否已加入；匿名时为 `false` |
| `isOwner` | `boolean` | 是 | 当前用户是否为圈主；匿名时为 `false` |
| `ownerId` | `string` | 是 | 圈主用户 ID |
| `createdAt` | `string` | 是 | 圈子创建时间 |

## 4. 获取圈子置顶内容

### 4.1 请求

```http
GET /api/v1/circles/{id}/pinned-items
```

该接口允许匿名访问，一次返回当前圈子的全部有效置顶内容。正文采用纯文本，换行使用 `\n`；前端不得将正文作为 HTML 直接注入。

### 4.2 响应

```json
{
  "items": [
    {
      "id": "pin-10001",
      "kind": "rules",
      "title": "圈子公约 · 请先阅读再发帖",
      "content": "1. 分享真实经验，拒绝营销与洗稿。\n2. 提问前请先搜索，避免重复。",
      "publisher": {
        "id": "10001",
        "name": "版主"
      },
      "viewCount": 3200,
      "status": null,
      "publishedAt": "2026-07-16T08:00:00Z",
      "pinnedAt": "2026-07-16T09:00:00Z"
    }
  ]
}
```

### 4.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | `CirclePinnedItem[]` | 是 | 按 `pinnedAt` 倒序排列的置顶内容；没有置顶时为空数组 |
| `items[].id` | `string` | 是 | 置顶内容 ID |
| `items[].kind` | `string` | 是 | `rules` 圈子公约、`announcement` 公告、`activity` 活动 |
| `items[].title` | `string` | 是 | 标题，最长 120 字符 |
| `items[].content` | `string` | 是 | 完整纯文本正文，最长 10000 字符 |
| `items[].publisher` | `object` | 是 | 发布者简要信息 |
| `items[].viewCount` | `integer` | 是 | 阅读数，非负整数 |
| `items[].status` | `string \| null` | 是 | 活动可为 `active` 或 `ended`；其他类型为 `null` |
| `items[].publishedAt` | `string` | 是 | 首次发布时间 |
| `items[].pinnedAt` | `string` | 是 | 置顶时间 |

置顶列表直接携带完整正文，因此点击条目放大查看时不需要再次请求。右侧“圈子公约”也必须复用 `kind=rules` 的同一份数据，禁止维护第二份静态公约。

## 5. 获取圈内帖子

### 5.1 请求

```http
GET /api/v1/circles/{id}/posts?limit=12
```

下一页请求：

```http
GET /api/v1/circles/{id}/posts?cursor=opaque_cursor_value&limit=12
```

### 5.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `cursor` | `string` | 否 | 无 | 上一页响应返回的不透明游标 |
| `limit` | `integer` | 否 | `20` | 每页数量，范围 1～40；详情页当前传 12 |

### 5.3 响应

```json
{
  "items": [
    {
      "id": "post-10001",
      "cover": {
        "url": "https://example.com/posts/cover.webp",
        "ratio": "4/5"
      },
      "tag": "经验",
      "title": "我用了 30 天 AI Agent，真正有用的是这 4 个场景",
      "circle": {
        "id": "ai-tools",
        "name": "AI 工具圈"
      },
      "author": {
        "id": "user-10001",
        "name": "林深",
        "avatarUrl": "https://example.com/avatar.webp",
        "avatarColor": "#245BDB"
      },
      "useful": {
        "count": 328,
        "liked": false
      },
      "createdAt": "2026-07-16T08:30:00Z"
    }
  ],
  "nextCursor": "opaque_cursor_value",
  "hasMore": true
}
```

### 5.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | `FeedItem[]` | 是 | 当前页帖子 |
| `nextCursor` | `string \| null` | 是 | 下一页游标，无下一页时为 `null` |
| `hasMore` | `boolean` | 是 | 是否还有下一页 |
| `FeedItem.id` | `string` | 是 | 帖子 ID |
| `FeedItem.cover.url` | `string` | 是 | 封面地址 |
| `FeedItem.cover.ratio` | `string` | 是 | 封面比例，如 `1/1`、`4/5`、`3/4`、`4/3`、`16/9` |
| `FeedItem.tag` | `string` | 否 | 帖子标签 |
| `FeedItem.title` | `string` | 是 | 帖子标题 |
| `FeedItem.circle` | `object` | 是 | 所属圈子简要信息 |
| `FeedItem.author` | `object` | 是 | 作者简要信息；`avatarUrl` 可为空 |
| `FeedItem.useful.count` | `integer` | 是 | “有用”数量 |
| `FeedItem.useful.liked` | `boolean` | 是 | 当前用户是否已点“有用” |
| `FeedItem.createdAt` | `string` | 是 | 发布时间 |

后端只返回已发布帖子，并按 `(createdAt, id)` 倒序排列。已加入圈子的用户可看到公开和圈内可见帖子；匿名用户和未加入用户只能看到 `visibility=public` 的帖子。

## 6. 加入或退出圈子

### 6.1 请求

```http
PUT /api/v1/circles/{id}/membership
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "joined": true
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `joined` | `boolean` | 是 | `true` 加入圈子，`false` 退出圈子 |

成功返回更新后的完整圈子详情。未登录点击“加入圈子”时，前端先打开登录框，不发送接口请求。圈主不能退出自己创建的圈子。

## 7. 错误响应

后端业务错误格式：

```json
{
  "code": "CIRCLE_NOT_FOUND",
  "message": "圈子不存在",
  "details": null
}
```

| HTTP 状态码 | 错误码 | 使用场景 |
| --- | --- | --- |
| `400` | `INVALID_CURSOR` | 圈内帖子分页游标无效或已失效 |
| `401` | `UNAUTHORIZED` 或统一认证响应 | 未登录调用成员接口 |
| `404` | `CIRCLE_NOT_FOUND` | 圈子不存在或未发布 |
| `409` | `OWNER_CANNOT_LEAVE` | 圈主尝试退出自己的圈子 |
| `422` | `VALIDATION_FAILED` | `joined` 缺失或请求参数不符合约束 |

## 8. 前端缓存与分页

React Query Key：

```text
["dalanbook", "circle", circleId]
["dalanbook", "circle", circleId, "pinned-items"]
["dalanbook", "circle", circleId, "posts"]
```

- 圈内帖子使用无限分页，每页请求 12 条。
- `hasMore=true` 时展示“加载更多帖子”。
- 下一页原样传递 `nextCursor`，前端不解析真实后端游标。
- “推荐/最新”只改变已加载数据的展示顺序，不进入当前帖子查询 Key。
- 置顶内容缓存 5 分钟；加载失败独立提示，不阻塞圈子资料和帖子流。
- 点击置顶条目在弹窗中显示接口返回的完整正文；分享按钮只复制当前圈子链接并展示 Toast，不新增分享接口。
- 修改成员状态后直接更新详情缓存，并失效 `['dalanbook', 'circles']` 前缀下的集合页缓存和当前圈内帖子缓存；重新请求帖子可正确切换圈内可见内容。
- 详情请求失败展示“圈子不存在”；帖子请求失败独立展示错误，不影响圈子资料。

## 9. 前端本地 Mock

`dalanbook-frontend/.env.local` 设置以下内容时，圈子详情、圈内帖子游标分页和成员操作使用同结构本地 Mock：

```dotenv
VITE_API_MODE=mock
```

Mock 仅在 `npm run dev` 生效；正式构建和 `VITE_API_MODE=real` 始终请求真实后端。Mock 同时提供圈子公约和活动两类置顶内容，便于验证列表、放大弹窗和侧栏公约复用。
