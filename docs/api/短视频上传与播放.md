# 短视频上传与播放 API 契约

短视频使用火山引擎 VOD。浏览器只拿到短期上传地址和短期播放地址，不能获得 VOD 长期凭据；视频二进制不经过业务服务，也不写入 `sys_oss`。

## 发布规则

- 单帖最多一条视频，或最多九张图片，不能混用。
- 首版允许 MP4、MOV、WebM，最大 200 MiB、时长不超过 3 分钟；后端以 VOD 回调的实际元数据为准。
- 视频帖发布后处于 `media_processing`，只有作者可查看；转码完成后自动变为 `published`，转码失败变为 `media_failed`。
- HLS 播放地址只在帖子权限校验后下发。公开帖子可匿名播放，`visibility=circle` 的帖子要求圈子成员身份。

## 获取上传凭证

```http
POST /api/v1/media/videos/upload-credentials
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{
  "fileName": "run.mp4",
  "contentType": "video/mp4",
  "size": 12582912
}
```

响应包含 `assetId`、`expiresAt`、`applicationId`、`spaceName`、`workflowTemplateId` 和短期 `uploadSts`。浏览器会收到 `uploadSts` 中的临时 AK/SK 和会话令牌，以便 `tt-uploader` 在本次上传中直传 VOD；这些凭据会过期，绝不是长期 AK/SK，不能存储到 localStorage、日志或环境变量。前端在 `workflowTemplateId` 存在时提交 `GetMeta` 与 `StartWorkflow`，以产出 HLS 和封面。旧部署可暂时返回 `uploadUrl`、`uploadMethod`、`uploadHeaders` 作为 PUT 兼容回退。

直传完成后必须调用：

```http
POST /api/v1/media/videos/{assetId}/complete
Authorization: Bearer <accessToken>
```

服务端据此提交 VOD 上传，再开始轮询资产状态。VOD 未配置时接口返回 `503 VOD_NOT_CONFIGURED`。

## 查询处理状态

```http
GET /api/v1/media/videos/{assetId}
Authorization: Bearer <accessToken>
```

仅视频上传者可读取。响应字段包括 `status`、`posterUrl`、`durationMs`、`width`、`height` 和失败时的 `failureReason`。状态为 `uploading`、`uploaded`、`processing`、`ready`、`failed` 或 `deleted`。

## 发布和播放

发布接口 `POST /api/v1/posts` 增加可选 `videoAssetId`。视频帖必须传空 `images`，并使用 `ratio: "9/16"`；视频资产必须归当前用户且尚未关联到其他帖子。

```http
GET /api/v1/posts/{postId}/video-playback
```

响应为 `{ "vid", "playAuth", "url", "expiresAt", "posterUrl", "durationMs" }`，其中 `vid` 和 `playAuth` 同时存在时前端优先使用 VePlayer 的 Vid 模式；没有播放凭证时以 `url` 作为 DirectUrl 回退。两种播放源至少返回一种。

前端使用 `@volcengine/veplayer` 播放，关闭 SDK 默认控制栏并使用短视频自定义控件。VePlayer 在播放源即将到期时调用本接口刷新地址或播放凭证。生产域名必须提供 `VITE_VOD_LICENSE_URL`，同时配置 `VITE_VOD_APP_ID` 用于 VOD 播放质量日志；两者都不是 AK/SK 或播放凭证。

## VOD 回调

```http
POST /internal/v1/vod/events
```

该接口仅供火山 VOD 调用。服务端必须验证 VOD 签名和 `SpaceName`，按回调事件 ID 幂等处理；上传元数据、转码完成、转码失败和删除事件驱动视频资产及关联帖子的状态。
