# 大蓝树前后端接口汇总

> 最后核对：2026-07-17
> 本文只汇总代码中已经存在的前端调用与后端接口，不承担概要设计、数据表设计和迁移说明。接口发生增删改时，应同步更新本文。

## 1. 汇总范围

| 端 | 代码位置 |
|---|---|
| 大蓝树用户端（React） | `dalanbook-frontend/src/lib/authApi.ts`、`dalanbook-frontend/src/lib/dalanbookApi.ts` |
| 管理端（Vue） | `plus-ui/src/api/login.ts`、`plus-ui/src/api/dalanbook/admin/`、`plus-ui/src/api/system/` |
| 用户端业务接口 | `DalanbookV1Controller` |

| 大蓝树管理接口 | `DalanbookAdminController` |
| 兼容接口 | `DalanbookController` |

接口状态：

- **已联调**：前端已有调用，后端已有对应接口。
- **后端已有**：后端已实现，当前大蓝树用户端尚未调用。
- **管理端已联调**：Vue 管理端已有调用，后端已有对应接口。
- **兼容接口**：旧版接口仍在后端保留，新版前端不再调用。

## 2. 公共约定

- 用户端业务接口统一前缀：`/api/v1`。
- 管理端大蓝树接口统一前缀：`/dalanbook/admin`。
- 登录注册接口同时兼容 `/auth/*` 与 `/api/v1/auth/*`；大蓝树 React 前端使用 `/api/v1/auth/*`，Vue 管理端使用 `/auth/*`。
- JSON 字段使用 camelCase。
- 已登录请求使用 `Authorization: Bearer <accessToken>`，并传递 `clientid`。
- 通用成功响应为 `{ "code": 200, "msg": "操作成功", "data": ... }`；部分创建接口返回 HTTP 201，标记已读返回 HTTP 204。
- 游标分页统一使用 `cursor`、`limit`，响应包含 `items`、`nextCursor`、`hasMore`。

## 4. 首页与发现

| 方法 | 地址 | 用途 | 当前状态 |
|---|---|---|---|
| GET | `/api/v1/home/categories` | 获取首页分类 | 后端已有 |
| GET | `/api/v1/home/feed` | 按频道和内容分类获取首页信息流 | 已联调 |
| GET | `/api/v1/home/circle-recommend` | 获取首页推荐圈子 | 后端已有 |
| GET | `/api/v1/home/left-nav` | 获取首页左侧导航数据 | 后端已有 |

| POST | `/api/v1/events/impression` | 上报帖子曝光事件 | 后端已有 |

主要查询参数：

- `/home/feed`：`categoryId`、`channel`、`cursor`、`limit`。
- `/home/circle-recommend`：`categoryId`。
- `/search/suggest`：`q`。

`channel` 可取 `recommend`、`following` 或 `latest`，默认 `recommend`。推荐频道保持原有按 `categoryId` 的兼容行为；最新频道按发布时间倒序，关注频道只返回当前登录用户关注作者的公开帖子。`categoryId` 可与频道组合筛选，关注频道在未登录时返回 `401`。

新的发布规则允许用户发布内容到任意圈子，不再要求先加入该圈子。前端和 Mock 已按此规则完成，当前真实后端的发布接口仍有入圈校验，后端需移除该校验后才能联调。`/circles/mine` 支持 `ownedOnly`，列表接口支持 `cursor`、`limit`。

关注请求体为 `{ "following": true }` 或 `{ "following": false }`；接口拒绝自关注，并仅在实际新增关注时生成一条 `user_follow` 通知。`/users/{id}/posts` 始终只返回公开帖子。`/me/posts` 需要登录，`type` 只能为 `published`、`liked` 或 `favorite`，因此他人无法通过公开用户地址读取喜欢或收藏列表。

## 10. 文档维护规则

1. 本文件只记录代码中真实存在的接口；纯规划接口写入对应概要设计，并标记“待实现”。
2. 新增接口时必须填写消费端和联调状态，避免“后端已写但前端未知”。
3. 用户端新接口统一放在 `/api/v1`；管理接口统一放在 `/dalanbook/admin`。
4. `/auth/*` 只作为 RuoYi 管理端兼容入口，大蓝树用户端统一调用 `/api/v1/auth/*`。
5. 请求体、响应体或错误码需要详细说明时，在本文件对应接口下增补，不再新建重复的“接口文档”。
